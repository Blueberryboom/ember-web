## Under development

A public Ember API is currently under development. No production endpoint or authentication method has been announced.

## Example only

The following is an illustrative convention, **not a live endpoint**:

```http
GET /v1/guilds/{guild_id}/settings
Authorization: Bearer <token>
```

Do not build against this example. Subscribe to Ember's official release notes for confirmed API details.
