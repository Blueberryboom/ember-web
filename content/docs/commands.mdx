> **Placeholder reference:** These command names and behaviours are examples, not a confirmation of currently available Ember commands.

## Moderation

| Example command | Intended use |
| --- | --- |
| `/moderate warn` | Record a moderation warning. |
| `/moderate timeout` | Temporarily restrict a member. |

## Utility

| Example command | Intended use |
| --- | --- |
| `/utility reminder` | Create a server reminder. |
| `/utility poll` | Start a simple poll. |

## Configuration

`/config welcome` and `/config logging` are example configuration commands.

## Information

`/info server` and `/info user` are example information commands.
